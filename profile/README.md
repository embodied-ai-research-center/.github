## 一、中心简介

具身智能研发中心聚焦人工智能与机器人交叉前沿领域，立足智能制造与智能服务产业发展需求，依托校企深度协同合作模式，构建集**科学研究、技术研发、实训教学、成果展示与科创培育**于一体的综合性研发育人平台。

中心硬件配置完善，搭载法奥意威协作机械臂、松灵遥操作机械臂套装、集萃农业采摘机械臂、众擎 PM01、T800 人形机器人、智身科技四足机器狗、幻尔履带式与麦克纳姆轮四驱小车、深度视觉感知设备等多元化智能硬件，覆盖**工业柔性作业、人形智能服务、移动智能体开发**等多方向研究场景。

中心组建由专任教师领衔、学生骨干协同参与的专项研发团队，深耕工业视觉检测分拣、轴孔精密装配、人形机器人智能巡逻、展厅智能导览、四足机器狗运动控制等落地性应用研究。

## 五、组织与协作

组织按「中心 — 项目组 — 仓库」三级结构管理，一个项目组对应一个团队、一个仓库，权限边界与代码资产一一对应：

```text
embodied-ai-research-center
├── research-center              中心管理层
├── team-pm01                    PM01 迎宾导览
├── team-t800                    T800 自主巡检
├── team-robot-dog               机器狗自主巡检
├── team-arm-teleop              机械臂遥操作
├── team-arm-franka-assembly     Franka 轴孔装配
├── team-arm-agri-picking        集萃农业采摘
└── team-tankbot                 Tankbot 小车
```

**协作规范**

- 代码变更统一通过 **Pull Request** 提交，由对应项目组组长评审后合并；
- 各仓库 `CODEOWNERS` 指定项目组团队为代码所有者，PR 自动请求组长评审；
- `main` 分支纳入统一保护策略，禁止直接推送；
- 组织级公共规范文件统一沉淀于 [`.github`](https://github.com/embodied-ai-research-center/.github) 仓库，由中心维护。
